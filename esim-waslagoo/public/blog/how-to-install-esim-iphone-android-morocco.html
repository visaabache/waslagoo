How to install a Morocco eSIM on iPhone and Android

Installing an eSIM takes a few minutes and needs an internet connection, so do it at home before you fly. Here are the three methods Airalo supports, the tap paths for each, and what to set afterwards so your phone uses the right line in Morocco.

The short answer

On Wi‑Fi, open the Airalo app, choose your eSIM, tap Install or share, then Start installation. Airalo calls this the direct method and describes it as the fastest. If it is not available on your phone, use the QR code or manual method below. Do it at home before you fly: Airalo says your eSIM only connects once you are at your destination.

Before you start

Check these first

  • Your phone supports eSIM and is not network-locked (how to check)
  • A stable internet connection, preferably Wi‑Fi
  • The Airalo app installed and signed in, with your plan bought
  • A few spare minutes: activation can take a short while, so do not leave the screen midway

Method 1: direct installation (fastest)

iPhone

  1. Open the Airalo app, go to My eSIMs and select your eSIM.
  2. Find Ready to use your eSIM? and tap Install or share.
  3. Tap Start installation, then Continue until activation starts.
  4. Allow the eSIM to activate if asked, and wait. It can take a few minutes, so do not exit the process.
  5. Tap Done when prompted, then follow the setup steps further down.

Android

  1. Open the Airalo app, go to My eSIMs and select your eSIM.
  2. Scroll to Ready to use your eSIM and tap Install or share.
  3. Tap Start installation and allow the eSIM to activate if asked.
  4. Wait for the confirmation that the eSIM has been installed.

Menu names and button labels change as apps and phone software are updated. If a screen looks different, follow the on-screen prompts or the instructions inside the Airalo app.

Method 2: QR code

You need to show the QR code on another screen, print it, or save it as an image and pick it from your photos.

iPhone

  1. In the Airalo app, open your eSIM and choose the QR code option. Show it on another device, or save the image.
  2. Open Settings, then Cellular (or Mobile Data).
  3. Tap Add eSIM (or Add Cellular/Mobile Data Plan), then Use QR Code.
  4. Scan the code, or choose the saved image from your photos.
  5. Tap Continue, allow the eSIM to activate and wait a few minutes. Tap Done when prompted.

Android

  1. In the Airalo app, choose the QR code option and show it on another screen, or print it.
  2. Open your phone's SIM settings and choose Add mobile network or Add eSIM. On Samsung phones this has typically been under Settings, Connections, SIM manager.
  3. Scan the QR code and enter the confirmation code if you are asked for one.

Method 3: manual entry

If scanning fails, you can type the details instead. In the Airalo app choose the Manual option to see your SM-DP+ address and activation code, plus a confirmation code if one is provided.

  • iPhone: Settings, Cellular (or Mobile Data), Add eSIM, Use QR Code, then Enter Details Manually. Paste in the SM-DP+ address, activation code and confirmation code (if asked), then tap Next and Continue.
  • Android: choose Add mobile network (or Add eSIM), then enter the code manually and paste in the SM-DP+ address and activation code.

After installing: set your phone up for Morocco

This part stops your phone using the wrong line and running up a bill:

  1. Label the eSIM something obvious, such as "Morocco". Labels help when you have more than one line.
  2. Choose the eSIM for mobile data. In your Cellular or Mobile Data settings, select the Morocco eSIM as the line for data.
  3. Keep your UK line for calls and texts if you want to stay reachable on your usual number, and switch data roaming off on the UK line so it never carries data by accident.
  4. Check whether data roaming needs to be on for the eSIM line. Airalo's instructions for each eSIM say whether it is required. If it is, switch it on for the eSIM line only.
  5. Make sure the eSIM line is enabled, then leave it until you land.

When you land in Morocco

  1. Switch flight mode off.
  2. Wait a minute or two. Your eSIM should connect to a supported Moroccan network on its own.
  3. When you see signal and data works, you are done. No kiosk, no queue.

If something goes wrong

ProblemWhat to try
The QR code will not scanShow it on a second screen at full brightness, or save the image and pick it from your photos. If that fails, use manual entry.
Stuck on "activating"Stay on the screen with Wi‑Fi on for a few minutes. If it errors, restart the phone and try the direct method again.
Installed, but no data in MoroccoCheck the eSIM line is on and selected for mobile data. Check data roaming for that line, toggle flight mode, and restart the phone. If it still fails, contact Airalo support in the app.

Frequently asked questions

Do I need Wi‑Fi to install an eSIM?

Airalo recommends a stable internet connection, preferably Wi‑Fi. That is why we suggest installing at home before you travel.

Can I install the eSIM before I get to Morocco?

Yes. Airalo says the eSIM only connects once you are at your destination, so installing at home is fine. Many travel plans start counting their validity when they first connect, but check the details of the plan you buy.

How long does installation take?

A few minutes. Airalo asks you not to leave the screen while the eSIM activates.

Can I use the eSIM and my UK SIM at the same time?

Yes, on eSIM phones. Keep your UK line for calls and texts, use the eSIM for mobile data, and turn data roaming off on the UK line.

What if my phone does not support eSIM?

Check our compatibility guide first. If it really does not, a SIM from the airport kiosks is the usual fallback: see the Agadir airport SIM card vs eSIM comparison.
